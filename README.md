# FORM TO PATTERN

하나의 SVG / PNG 조형에서 복합 유닛과 패턴, 모션을 만드는 로컬 그래픽 편집 도구입니다. 서버 업로드나 로그인이 필요하지 않습니다.

## 개발

Node.js 22 이상을 사용합니다. 이 환경에서는 Node.js 24.19.0과 npm 11.9.0으로 검증했습니다.

```sh
npm ci
npm run dev -- --port 5173
```

프로덕션 빌드는 `npm run build`, 빌드 결과 실행은 `npm run preview`입니다. 아이콘과 폰트도 패키지에 포함되어 런타임 외부 요청이 필요하지 않습니다.

```sh
npm test
# 별도 터미널에서 개발 서버를 실행한 상태로:
npm run test:browser
```

브라우저 테스트는 `/usr/bin/chromium`을 사용하며, 다른 설치 위치는 `CHROMIUM_PATH`로 지정합니다. 테스트 결과 이미지는 `/tmp/form-pattern-*.png`, 출력 검증 파일은 `/tmp/form-pattern-*`에 생성됩니다.

## 편집 흐름

1. 기본 데모를 사용하거나 왼쪽 카드에 SVG / 투명 PNG를 놓습니다.
2. A–F 프리셋을 선택합니다. 원본만 교체해도 유닛, 배열, 표현, 시드와 모션 설정은 유지됩니다.
3. 오른쪽 조형 / 유닛 / 배열 / 색·효과 패널에서 값을 조절합니다. 슬라이더와 숫자 입력은 같은 설정을 바꿉니다. 밀도는 고정 캔버스에서 셀 크기와 반복 개수를 연동하며, 간격은 셀에 추가되는 여백입니다.
4. 모션에서 타임라인을 이동하거나 재생합니다. 형성 과정과 7종 루프, 시작·끝 상태 저장 후 상태 간 이동을 제공합니다. 미리보기 속도는 재생 속도만 바꾸며 출력 길이와 프레임 계산은 길이 / FPS를 따릅니다.
5. 비교에서 현재 시안을 고정하거나 밀도 5단계 / 시드 변주를 선택합니다. 고정한 시안은 원본도 보관하므로 다른 조형 적용 전후를 비교할 수 있습니다.
6. JSON 프로젝트 파일을 별도로 저장합니다. 로컬 자동 저장은 현재 브라우저에만 보관되며 대용량 파일은 저장 공간 제한이 있습니다.
7. SVG / PNG / 정지 반복 타일 / 전개 이미지 / PNG 프레임 ZIP으로 내보냅니다. 결과에는 편집 가이드가 포함되지 않습니다.

### 다색 팔레트와 효과

오른쪽 **색·효과 → 나만의 팔레트**에서 4·5·6색을 선택하세요. 색상 칸을 클릭하거나 HEX 코드를 입력하면 다색 모드가 켜집니다. **랜덤 팔레트 만들기**는 조형·배열·배경·그레인 시드를 유지하며 팔레트만 생성합니다. 색상은 렌더 순서나 재생 프레임이 아닌 격자 위치와 내부 조형 ID에 따라 배분됩니다. 다색 모드를 끄면 기존 주/보조 역할 색상을 사용합니다. PNG는 원본 픽셀을 유지하고, SVG의 원본 색 유지는 팔레트를 적용할 때 꺼집니다.

**그레인 켜기 / 블러 켜기**로 효과를 각각 켜고, **그레인 강도 / 블러 강도**를 조절하세요. 끈 상태에서도 강도값은 보관됩니다. 처음 켤 때는 0보다 큰 기본 강도를 적용합니다. 역할별 적용 대상도 유지합니다. 팔레트·효과·시드는 JSON, 자동 저장, 실행 취소, SVG/PNG/프레임 출력에 함께 반영됩니다. 기존 JSON 프로젝트도 불러올 수 있습니다. 다색 타일은 색상 배분까지 반복되도록 N×N 셀의 상위 타일로 출력합니다.

실행 취소: Ctrl/Cmd+Z, 다시 실행: Ctrl/Cmd+Shift+Z, 모션 재생: Space.

## 구조

- `src/engine.js`: 원본 참조, A–F 배열, 안정적인 인스턴스 ID, 역할별 표현, 시간에 따른 결정적 SVG 계산. 프레임 ZIP과 미리보기는 동일한 `renderSVG`를 사용합니다. 시퀀스는 k/N으로 출력하며 끝점을 중복하지 않습니다.
- `src/main.js`: 한국어 편집 UI, 입력 정규화·SVG 정리, 히스토리, 비교, 로컬 저장과 내보내기.
- `src/style.css`: 데스크톱 편집 화면과 좁은 화면 레이아웃.
- `tests`: 렌더링 규칙과 실제 Chromium 사용자 흐름 검증.

## 해석과 지원 범위

PNG 레퍼런스 03–17은 현재 제공되지 않았습니다. 프리셋은 전달받은 문서의 관찰 설명으로 재구성했고, 기본 계단형 SVG는 근사 벡터입니다. F는 원작 제작법을 확인한 구현이 아닙니다. 모션은 새로 제안한 기능입니다.

SVG는 도형 경계 중심으로 정규화하고 종횡비, 내부 구멍, 복수 패스, 그룹과 로컬 ID 참조를 유지합니다. 스크립트, 이벤트, 외부 참조, HTML, 외부 CSS, SVG 애니메이션은 제거합니다. 기본 도형, 그룹, 그라디언트, 마스크와 클립을 지원하며 텍스트는 패스로 변환해 불러오세요. CSS 클래스 기반 스타일은 원본 파일에서 프레젠테이션 속성으로 변환하는 것이 좋습니다. PNG는 알파 경계를 기준으로 정규화하며 벡터화하지 않습니다. PNG에는 벡터용 채움·외곽선이 적용되지 않습니다.

정지 타일은 현재 셀의 상위 반복 단위이며 3×3 미리보기를 제공합니다. **모션의 공간 반복은 보장하지 않습니다.** 질감 포함 SVG는 SVG 필터를 사용하므로 외부 편집 프로그램의 호환성이 다를 수 있습니다. MP4 / GIF 인코더는 연결되어 있지 않아 활성화된 출력 옵션으로 제공하지 않습니다. 프레임 ZIP에는 메모리 보호 한도가 있으며 크기·FPS·길이를 줄여 출력할 수 있습니다.

현재 도구는 프리셋의 기본 규칙을 실험하는 편집기입니다. 레퍼런스 원본과의 픽셀 단위 일치, 자유 키프레임 편집, 임의 패스 모핑은 제공하지 않습니다.
